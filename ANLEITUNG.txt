================================================================================
  WINDOWS — EINMAL-SETUP (ca. 10 Minuten)
================================================================================

1. Python installieren (falls noch nicht vorhanden):
   https://www.python.org/downloads/
   WICHTIG: Beim Installieren "Add python.exe to PATH" ankreuzen!

2. Den ganzen Ordner "englisch word widows" auf den Desktop legen.

3. Doppelklick auf:
      setup.bat

   Das installiert automatisch alle Pakete und Chromium.

4. API-Key:
   - .env Datei im Ordner oeffnen (Notepad)
   - Falls .env fehlt: .env.example kopieren und in .env umbenennen
   - AI_API_KEY=... eintragen (Christoph gibt den Key)

5. Membean-Login:
   - Doppelklick auf start.bat
   - [2] Bei Membean einloggen
   - Im Browser mit DEINEM Membean-Konto einloggen
   - Auf dem Dashboard bleiben, Enter im Terminal druecken


WINDOWS — JEDEN TAG
-------------------
   Einfachste Methode:
      Doppelklick auf start.bat

   Oder in der Eingabeaufforderung (cmd):

      cd %USERPROFILE%\Desktop\"englisch word widows"
      venv\Scripts\activate.bat
      python main.py


================================================================================
  MAC — EINMAL-SETUP
================================================================================

1. Ordner auf den Desktop legen.

2. Terminal oeffnen und einfuegen:

   cd ~/Desktop/"englisch word widows"
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   playwright install chromium

3. .env mit AI_API_KEY fuellen (siehe Windows Schritt 4).

4. Login wie oben — start.command oder:
   source venv/bin/activate && python main.py start


MAC — JEDEN TAG
---------------
   Doppelklick auf start.command
   (Falls blockiert: Rechtsklick -> Oeffnen -> Oeffnen)


================================================================================
  MENUE (Windows + Mac)
================================================================================

   [1]  Training starten
   [2]  Bei Membean einloggen (wenn Session abgelaufen)
   [3]  Einstellungen (Browser)
   [4]  KI testen
   [5]  Wortliste anzeigen
   [0]  Beenden

   Session-Dauer bei [1]: 5, 10, 15, 20, 25 oder 30 Minuten
   Stoppen: Ctrl+C im Terminal — Browser waehrend Training nicht schliessen!

FEHLERBEHEBUNG — WINDOWS
------------------------
   "Python nicht gefunden"     -> Python installieren + PATH ankreuzen
   "venv fehlt"                -> setup.bat ausfuehren
   Session abgelaufen          -> Menue [2] Login
   KI funktioniert nicht       -> Menue [4], AI_API_KEY in .env pruefen
   start.bat schliesst sofort  -> setup.bat zuerst ausfuehren


FEHLERBEHEBUNG — MAC
--------------------
   start.command blockiert     -> Rechtsklick -> Oeffnen
   "venv not found"            -> Mac-Einmal-Setup Schritt 2
