================================================================================
  MEMBEAN BOT — SETUP GUIDE
  Works on Windows and Mac.
================================================================================

DOWNLOAD (no GitHub login needed)
---------------------------------
   https://github.com/cortenburg28-arch/membean-bot/archive/refs/heads/main.zip

   Unzip -> open the folder -> follow WINDOWS steps below.


FOLDER CONTENTS
---------------
   membean-bot/
     ├── start.bat         <- double-click to run (Windows)
     ├── setup.bat         <- one-time setup (Windows)
     ├── start.command     <- double-click to run (Mac)
     ├── ANLEITUNG.txt
     ├── main.py
     └── ...


================================================================================
  WINDOWS — ONE-TIME SETUP (~10 minutes)
================================================================================

1. Install Python (pick ONE method):

   A) Terminal — no website (recommended):
      winget install Python.Python.3.12

   B) Website:
      https://www.python.org/downloads/
      IMPORTANT: check "Add python.exe to PATH" during install!

2. Put the project folder on your Desktop (or anywhere you like).

3. One-time setup — double-click:
      setup.bat

   Or in Command Prompt (cmd):

      cd %USERPROFILE%\Desktop\membean-bot
      python -m venv venv
      venv\Scripts\activate.bat
      python -m pip install --upgrade pip
      pip install -r requirements.txt
      playwright install chromium
      copy .env.example .env

4. API key:
   - Open .env in Notepad
   - Set: AI_API_KEY=...  (Christoph sends the key privately)
   - Do NOT commit or upload .env to GitHub

5. Membean login:
   - Double-click start.bat
   - Press [2] Log in to Membean
   - Log in with YOUR Membean account in the browser
   - Stay on the dashboard, press Enter in the terminal


WINDOWS — EVERY DAY
-------------------
   Easiest:
      double-click start.bat

   Or in Command Prompt (cmd) — copy all 3 lines:

      cd %USERPROFILE%\Desktop\membean-bot
      venv\Scripts\activate.bat
      python main.py start


WINDOWS — ALL TERMINAL COMMANDS (English)
-----------------------------------------
   Menu (recommended):
      python main.py start

   Log in to Membean:
      python main.py login

   Check saved session:
      python main.py verify

   Test AI:
      python main.py test-ai

   Start training (full auto):
      python main.py run

   Pick session length first:
      python main.py run --ask-duration

   Fixed 15-minute session:
      python main.py run --minutes 15

   Settings (web UI):
      python main.py settings

   Stop:
      Ctrl+C


WINDOWS — PowerShell (instead of cmd)
-------------------------------------
      cd "$env:USERPROFILE\Desktop\membean-bot"
      .\venv\Scripts\Activate.ps1
      python main.py start

   If Activate.ps1 is blocked:
      Set-ExecutionPolicy -Scope CurrentUser RemoteSigned


================================================================================
  MAC — ONE-TIME SETUP
================================================================================

1. Put the folder on your Desktop.

2. Terminal:

      cd ~/Desktop/membean-bot
      python3 -m venv venv
      source venv/bin/activate
      pip install -r requirements.txt
      playwright install chromium
      cp .env.example .env

3. Add AI_API_KEY to .env (see Windows step 4).

4. Login: double-click start.command, or:

      source venv/bin/activate && python main.py start


MAC — EVERY DAY
---------------
   Double-click start.command
   (If blocked: right-click -> Open -> Open)


================================================================================
  MENU (Windows + Mac)
================================================================================

   [1]  Start training
   [2]  Log in to Membean (if session expired)
   [3]  Settings (browser)
   [4]  Test AI
   [5]  Show word list
   [0]  Quit

   Session length at [1]: 5, 10, 15, 20, 25, or 30 minutes
   Do NOT close the browser during training.

TROUBLESHOOTING — WINDOWS
-------------------------
   "Python not found"          -> install Python, check PATH, reopen terminal
   "venv missing"              -> run setup.bat
   Session expired             -> menu [2] Log in again
   AI not working              -> menu [4], check AI_API_KEY in .env
   start.bat closes instantly  -> run setup.bat first
   winget not found            -> use python.org installer (step 1B)


TROUBLESHOOTING — MAC
---------------------
   start.command blocked       -> right-click -> Open
   "venv not found"            -> Mac one-time setup step 2
